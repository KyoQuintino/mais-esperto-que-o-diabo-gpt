# Mais Esperto que o Diabo — Site de divulgação

Landing page responsiva do e-book **Mais Esperto que o Diabo**, com identidade visual cinematográfica em preto, dourado e vermelho.

## Arquivos
- `index.html` — página completa de apresentação e vendas.
- `styles.css` — layout responsivo para celular e desktop.
- `script.js` — ano automático no rodapé.
- `assets/capa-destaque.svg` — arte vetorial de destaque.
- `assets/divulgacao-hotmart.svg` — banner promocional para divulgação.
